Modos de jogo

VALORANT possui diferentes formas de jogar. Entre elas estão partidas competitivas e modos voltados para treinamento ou partidas mais rápidas.

  1. Competitivo
  2. Sem Classificação
  3. Disputa da Spike
  4. Personalizada
O que é uma partida personalizada?

É uma partida criada para permitir que os jogadores configurem uma sala e joguem de acordo com as opções disponíveis.

O que é o modo competitivo?

É um modo com sistema de classificação, no qual os jogadores disputam partidas para avançar ou manter sua classificação.

Os modos podem receber alterações ao longo do tempo.
